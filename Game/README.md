# 游戏运行与操作

本目录是 Godot 4.7.2 工程。文件与模块职责见 [ARCHITECTURE.md](ARCHITECTURE.md)；客户、NPC 与地图的内容编辑操作统一见 [编辑器 README](../tools/editors/README.md)。

## 打开方式

在 Godot 中打开 `project.godot`，按 **F5** 进入主菜单。点击“开始”，在三个栏位中读取存档，或为新基地命名后创建存档。已有栏位不会被创建操作覆盖。

Windows 启动入口：

| 文件 | 用途 | 日志 |
| --- | --- | --- |
| `启动Demo.cmd` | 直接运行游戏；保留原启动器文件名 | `../test/results/logs/play.log` |
| `打开编辑器.cmd` | 以 `--editor --path` 打开本目录，用于编辑场景、脚本和 F5 试玩 | `../test/results/logs/editor.log` |

两个脚本默认使用 `Z:\soft\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe`。路径不同时，修改各脚本内的默认路径；其中“打开编辑器.cmd”也支持已有的 `GODOT_EXE` 环境变量。脚本不会下载引擎。`project.godot` 是工程配置，未关联 Godot 时不能当作可执行程序运行。

| 入口或操作 | 功能 |

| 窗口 | 进入独立交易页面 |
| 床 | 休息、结算一天并保存 |
| 柜子 | 整理储物和背包 |
| 电脑 | 阅读新闻，进入线路图、查看站点报价并前往目的地 |
| 车门 | 整理预备仓库、租用防护服后出站探索 |
| 屏幕悬停 | 查看当天信息；点击不打开线路图 |

新档电脑作为物品存放；默认家具若与当前素材占位冲突，会移入临时收纳，进入装修后需重新摆放或分解。正常模式悬停家具显示白色描边和功能说明。喝水、进食、充电等操作使用车厢工具栏；连续缺水、缺食或欠费会结束本轮。

### 交易

每位顾客对应一张订单，需求按生活补给、电力用品、工业材料或文书旧物分类。把玩家背包或顾客商品拖入订单区域，再点击“确认交易”。确认前不会交换商品或款项。

顾客从玩家买货会减少其预算，总价超预算时显示“买不起”；顾客向玩家卖货会增加其预算。玩家售货收入优先偿还欠费。“送客”结束当前未完成订单，不交换商品和款项，仍消耗一次到访名额。顾客从左入场、向右离场，窗口只显示上半身。

每日人数按站点限制，每位顾客一天最多进入交易窗口一次，跨站共享去重记录。关闭交易不会重抽当前订单。满足条件时先进入 NPC 剧情；好感度、阵营信任度和完成事件可影响后续见面。

### 装修与储物

进入装修后只显示装修功能。点击家具选中，长按左键 **0.5秒** 后拖动；鼠标右上方显示蓄力圈。松开时落点有效才提交，Esc 取消操作。选中家具后，其右上方显示临时收纳、分解及储物操作。临时收纳只用于本次调整，完成装修前必须清空；分解需要二次确认并消耗/返还配方材料。

每节车厢提供35×12正方形布置网格、四个独立栏杆挂点。电脑占3×2格并保持比例居中，柜子3×12、门8×12、床8×2；屏幕为悬挂物，自定义悬挂点对齐车厢挂点；参考格不限制放置。背包或柜子内的电脑是2×2物品，可以旋转，摆成家具时恢复底面朝下。收纳为物品时需要足够的储物空间。

扩建每次消耗钢板×2、螺丝×4、工具×1，最多三节。每增加一节，行车和跨站接应增加10度/站，每日结算增加2度；确认页会显示材料和耗电变化。布置和扩建随床铺日结保存。

## 出站探索

车门旁的预备仓库容量由家具目录配置（可在装修中移动，距门不能超过目录配置的6个家具格）；点击预备仓库打开与其他储物家具一致的储物界面；只有点击车门进入出站整备界面，在仓库与随身背包间拖拽物品，决定携带或留下。只保留普通/加强防护服租赁（30/50度）。手电筒、撬棍、扳手、大背包都是实体物品，存放仓库时不生效；背包位置装备小背包时为5×4，大背包为6×5；背包物品仅放在普通储物格中不会扩容。未装备背包时没有背包储物格，卸下前须清空，切换背包容量不足时保留原状。允许不带手电出发，使用照明仍需携带手电并安装有电电池。已登记的站点加载可行走街区；未登记站点使用简化搜刮界面。邮电新村、四平路、同济大学默认共用邮电街区，其他关卡由 `content/registry.json` 登记。

| 按键或操作 | 功能 |
| --- | --- |
| A / D、左右方向键 | 在街道或建筑内移动 |
| Shift + 方向键 | 消耗体力跑步 |
| E | 与附近 NPC 交谈、拾取、穿巷、进出建筑、上下楼、检查汽车或撤离 |
| B / 背包按钮 | 展开或收起右侧背包 |
| 空格 | 使用左上装备栏的主动道具 |
| 1 | 在暗处开关手电筒 |
| R / 鼠标滚轮 | 旋转当前选中或拖动的储物物品 |
| 右键 / Esc | 取消物品选择 |
| 七号电池 | 放入主动位后按空格更换手电电池 |
| F11 | 全屏与最大化切换 |

暗处可开手电辅助看清环境，拾取不要求开灯；室外或光照充足时自动关闭手电，满电基础照明约20秒。每次探索基础时限90秒；超时丢失随身物品及安装电池，并产生防护服赔偿。原站撤离免费，跨站接应按路线和车厢数量扣除车电。NPC 对话和检查汽车只阻止行走，不暂停探索计时；打开游戏设置会暂停计时。

可行走探索画面铺满窗口，背包按钮紧贴右边缘居中，体力条位于左下。左上同时显示剩余时间与手机电量形状的进度条，剩余50%变黄、15%变红，装备/主动位统一显示在其下方。背包中将物品拖到左上统一装备栏的主动位，即可释放背包占格；换装空间不足时保留原状。符合2×2占位的治疗物品可恢复其配置生命值，水/口粮可满足当日饮食，材料无主动使用效果。

探索人物使用新临时防护服行走动画。走速为188（较原235降低20%），跑速282，为走路1.5倍。体力上限100，跑步每秒消耗25，停止跑步0.6秒后每秒恢复20；耗尽后需松开 Shift 并恢复到25才能再跑。

行走播放沙沙摩擦循环，跑步播放哒哒落脚循环，停步立即停声；生成及候选评估见 [脚步音效说明](assets/audio/footsteps/README.md)。行走/跑步会发出脚步声，声音范围分别为半个/1.5个人高，地面圆圈表示声音范围。变异老鼠在街道巡逻，前向视锥及近身圆形范围内每0.1秒增加10警觉，只有声音时增加5；满100后追踪，不跨街道或进入建筑。失去感知后警觉逐渐下降。扑击命中会减少5秒探索时间，并在2秒内减速20%；老鼠攻击后停留2秒。

靠近可互动物品会调用通用高亮组件仅显示白色描边；描边与物品一起受环境光照影响，功能提示统一在探索交互提示区域显示。建筑内柜子按点位概率与权重生成物资，靠近后按 E 或点击打开，再拿入背包。柜子界面不暂停探索，空柜子会明确显示为空；暗处也能拾取。已领取物品不会因重新打开柜子而刷新。

同济大学汽修培训解锁扳手拆解技能与对应零件。靠近汽车按 E 打开面板，规则会检查技能、扳手是否装备、当日拆解记录和背包空间。背包/柜子支持“整理”和“一键放置选中”，Shift+点击快速转移；探索支持拾取附近散落物资，柜子支持一键拿取全部，可放不下的物品保持原处。走路音量降低25%、跑步提高25%（按线性振幅计算）。

详细事件流与调整入口见 [探索架构](EXPLORATION_ARCHITECTURE.md)。

## 存档与设置

- 正常三栏位存档：`user://saves/slot_1.json` 至 `slot_3.json`。`user://` 是 Godot 的项目用户数据目录，不等同于本工程的 `saves/`。
- 床铺休息才会推进日期并保存；返回主菜单或退出不会自动保存。
- 原单栏位兼容入口检查 `saves/cabin_slot.json`：源码运行时相对于 Game，导出运行时相对于可执行文件目录。
- `saves/legacy_demo/` 仅归档旧调试存档，不自动覆盖或载入正常栏位。
- 音量和全屏设置位于 `user://settings.cfg`，修改后立即保存。
- 当前存档版本16，兼容1–15版。旧版缺失的关系状态以默认值初始化；具体迁移边界见 [编辑器 README](../tools/editors/README.md#7-存档与生效时机)。

## 早期横版原型

`scenes/game/main.tscn` 是保留的早期可玩原型，在 Godot 打开该场景后按 **F6** 运行。它包含地下设施、移动/跳跃/爬梯、物资检查、回收证、汽修委托、程序绘图与声音；F5 主入口使用 Home 流程。

原型独有操作：空格跳跃、W/S或上下键爬梯、Tab打开终端、Q放下物资、F驱赶动物、L开关手电、M静音。R在该原型中用于检测物资。原型代码为 `scripts/main.gd`、`world.gd`、`player.gd`、`state.gd`；其中 `state.gd` 同时是当前车厢状态基类，继续保留。

## 独立内容编辑器

在“项目 → 项目设置 → 插件”启用 **Metro 内容编辑器**，从右侧面板点击 **打开独立编辑器窗口**，也可勾选 **打开项目时自动启动**。编辑器使用独立程序窗口，不在 Godot 内挤占编辑区，也不打开系统浏览器。打开后自动保存游戏项目、编辑器目录与 Godot 引擎的双向路径；各协作者的绝对路径只保存在本机配置中。

地图、关卡、客户/NPC、对话及全部内容目录复用原编辑器界面与校验。首次安装 `tools/editors/requirements-desktop.txt` 中的 Python 桌面依赖；详细启动、功能对照及保存规则见 [编辑器手册](../tools/editors/README.md)。

## 家具、支撑与装修检查

预备仓库、窗户与其他家具使用同一个家具类，可在装修中长按0.5秒拖动，并可临时收纳、重新摆放或分解。无墙面占位的家具不能悬空，可以放在地板或其他家具实物格的上边缘；墙面占位不与地面家具互相占格。吊杆与挂件显示在其他家具上方。

点击“检查装修”可查看未完成项。临时收纳仍有家具、缺少门窗、存在悬空家具或不满足距离的家具时，不能完成装修。带物品属性的家具可以收进柜子、预备仓库等储物家具；储物空间不足时保留原家具，所有储物家具均须清空后才能分解。

选中储物家具后点击右上方“储物格”，在屏幕最左侧显示该家具的储物空间，右侧装修场景继续操作。物品类家具长按0.5秒后拖入具体格子收纳；也可将格内有家具属性的物品拖回车厢摆放，恢复底面朝下。装修中仅管理储物内容，不显示或调节储物格行列；容量由家具定义决定。

### 建造与分解

装修工具栏的“建造”打开已知家具列表。每项使用统一96×72贴图框，按比例缩放素材，并分别显示技术和材料需求。缺少条件的条目变灰，其中已满足的条件仍为绿色；全部满足的条目自动置顶并按ID字母顺序排列，材料或技术变化时列表自动更新。成功放置才扣除材料。关联物品的家具需要相应物品。

每节初始或扩建车厢配备独立门窗；之后可以花费资源建造或分解，全车必须保留至少一个已放置的门和窗。分解前会确认费用和回收材料；储物未清空、材料不足或无处存放回收物时不执行。车厢35×12可布置格最下边界明确作为地面，以实际占用格判定支撑。

家具占位编辑统一使用“实物格 / 墙面格”：同一家具内互斥，不同家具可以前后重叠；实物格在墙面格前。没有墙面格的家具必须由地面或平整实物格支撑。

预备仓库摆放失败时，提示会区分“被哪件家具占用”“下方缺少实物支撑”及“最近占位距离超限”。当前3×2预备仓库在旧位置（第0车厢，x=17、y=8）不接地，下方也没有实物格承托，所以即使距离门为0仍会失败；可下移到y=10，或放在窗户实物格上方。窗户底部有实物格，与其重叠的位置仍不可放置。物品类家具无需专门收纳按钮，直接拖入左侧储物格即可。

出站整备与探索共用四个装备位置：头盔随所选防护服自动变化；背包位置通过拖拽装备任意带“储物类”标签的物品，按编辑器配置提供储物空间（小背包/大背包分别为5×4/6×5），点击可展开或收起；口袋为2×2储物格；主动位为2×2且只放一件物品，空格使用。出站整备时，预备仓库在左、背包储物区居中，背包/口袋/主动位置在最右纵向排列，所有格子统一为36像素；“一键整理背包”和“一键转移”位于背包储物页底部，随该页面一起展开/收起；装备背包后自动展开中间储物区，卸下后自动折叠。未装备背包时只能使用装备格，B也不会创建额外储物空间。七号电池放入主动位按空格更换，取消独立电池选择与逐项工具状态列表。

放置、空位提示、出发检查统一按物品实际占位格判断，贴图透明区和编辑画布空格不占空间。拖拽保留鼠标抓取的物品格，旋转/镜像时同步转换；有空位但旧位置越界时，出发会尝试无损整理。
